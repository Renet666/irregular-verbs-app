# Irregular Verbs Learning App

A Django web application to help children learn English irregular verbs through interactive flashcards and quizzes.

## Features
- Browse verbs by level (Beginner A1/A2 → Advanced C1/C2)
- Interactive flashcard mode with real-time answer checking
- Score tracking and "play again" functionality
- Responsive design (works on mobile)

## Tech Stack
- **Backend:** Django, Python
- **Frontend:** Vanilla JavaScript, HTML, CSS
- **Database:** SQLite
